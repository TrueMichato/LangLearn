# English-Spanish Cognates & False Friends

English and Spanish share thousands of cognate words due to their shared Latin heritage. Recognizing these cognates can instantly expand your active vocabulary by hundreds of words. But beware: some lookalikes are **false friends** that will lead you straight into embarrassing mistakes.

## True Cognates: Similar Form, Same Meaning

Many common English words have near-identical Spanish counterparts:

| English | Spanish | Notes |
|---|---|---|
| information | **información** | feminine |
| hospital | **hospital** | identical |
| problem | **problema** | ⚠️ masculine: *el problema* |
| moment | **momento** | |
| animal | **animal** | identical |
| doctor | **doctor** | identical |
| idea | **idea** | identical |
| music | **música** | accent on first syllable |
| possible | **posible** | |
| important | **importante** | |
| different | **diferente** | |
| professor | **profesor** | one *s* in Spanish |
| restaurant | **restaurante** | |
| university | **universidad** | |

## Spelling Patterns for Cognates

Learn these patterns and hundreds of words become instantly accessible:

| English ending | Spanish ending | Examples |
|---|---|---|
| -tion | **-ción** (feminine) | nation → nación, station → estación, action → acción |
| -ty | **-dad** (feminine) | university → universidad, reality → realidad, liberty → libertad |
| -ous | **-oso/a** | famous → famoso, generous → generoso, nervous → nervioso |
| -ble | **-ble** | possible → posible, incredible → increíble, comfortable → confortable |
| -ist | **-ista** | artist → artista, journalist → periodista, tourist → turista |
| -ism | **-ismo** | capitalism → capitalismo, tourism → turismo |

Key notes on gender: **-ción** words are always **feminine** (*la nación, la estación*). Words ending in **-ma** that came through Greek (*el problema, el sistema, el tema, el clima*) are **masculine** despite the -a ending — a common trap.

## False Friends: Words That Are NOT What They Look Like

These are the most dangerous words for English speakers — they look familiar but carry entirely different meanings:

| Spanish word | Looks like English... | Actual Spanish meaning | English word you wanted |
|---|---|---|---|
| **embarazada** | embarrassed | pregnant | avergonzada |
| **éxito** | exit | success | salida |
| **sensible** | sensible | sensitive | sensato / razonable |
| **constipado/a** | constipated | having a cold / stuffy nose | estreñido/a |
| **ropa** | rope | clothes / clothing | cuerda |
| **carpeta** | carpet | folder / binder | alfombra |
| **librería** | library | bookstore | biblioteca |
| **asistir** | to assist | to attend | ayudar |
| **largo/a** | large | long | grande |
| **molestar** | to molest | to bother / annoy | (much stronger meaning in English) |

## Tips for Using Cognates Effectively

1. **Trust the pattern** — if an English word ends in -tion, try -ción and you will usually be right.
2. **Check the gender** — cognates in -ción are always feminine (*la nación*); Greek-origin -ma words are masculine (*el problema, el sistema*).
3. **Accent marks** — the Spanish version often has a written accent where English does not: *música, nación, público, teléfono*.
4. **Memorize the false friends** — *embarazada* and *éxito* cause the most embarrassing mix-ups in real conversation.
