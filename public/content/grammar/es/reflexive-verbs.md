# Reflexive Verbs (lavarse, vestirse)

Reflexive verbs express actions that the subject performs **on or for themselves**. You can recognize them by the **-se** ending on the infinitive: *lavarse* (to wash oneself), *vestirse* (to get dressed). They appear constantly in daily-routine vocabulary and some change meaning entirely when used reflexively.

## Reflexive Pronouns

| Subject | Reflexive pronoun |
|---------|-------------------|
| yo | **me** |
| tú | **te** |
| él / ella / usted | **se** |
| nosotros | **nos** |
| vosotros | **os** |
| ellos / ustedes | **se** |

## Conjugating lavarse (to wash oneself)

Drop the **-se**, conjugate the stem verb, then place the matching pronoun **before** it:

| Pronoun | Conjugation | Pronunciation |
|---------|-------------|---------------|
| yo | **me lavo** | meh LAH-boh |
| tú | **te lavas** | teh LAH-bahs |
| él / ella / usted | **se lava** | seh LAH-bah |
| nosotros | **nos lavamos** | nohs lah-BAH-mohs |
| vosotros | **os laváis** | ohs lah-BYSS |
| ellos / ustedes | **se lavan** | seh LAH-bahn |

## Where to Place the Reflexive Pronoun

| Structure | Pronoun position | Example |
|-----------|-----------------|---------|
| Conjugated verb alone | **Before** the verb | **Me lavo** las manos. |
| Conjugated verb + infinitive | Before conjugated **or** attached to infinitive | **Me quiero lavar** = **Quiero lavarme** |
| Conjugated verb + gerund | Before conjugated **or** attached to gerund | **Me estoy duchando** = **Estoy duchándome** |
| Affirmative imperative | **Attached** to the end of the verb | **¡Lávate!** / **¡Levántate!** |
| Negative imperative | **Before** the verb | **No te laves** con agua fría. |

> ⚠️ When the pronoun attaches to the gerund, add an accent to keep the stress: *duchando* → **duchándome**; *levantando* → **levantándose**.

## Common Reflexive Verbs — Daily Routine

| Infinitive | Meaning |
|-----------|---------|
| **levantarse** (leh-bahn-TAR-seh) | to get up |
| **despertarse** (dehs-pehr-TAR-seh) | to wake up |
| **ducharse** (doo-CHAR-seh) | to shower |
| **peinarse** (peh-EE-nar-seh) | to comb one's hair |
| **vestirse** (behs-TEER-seh) | to get dressed |
| **acostarse** (ah-kohs-TAR-seh) | to go to bed |
| **llamarse** (yah-MAR-seh) | to be called / named |
| **sentirse** (sehn-TEER-seh) | to feel |
| **divertirse** (dee-behr-TEER-seh) | to have fun |

- **Me llamo María** (meh YAH-moh mah-REE-ah) — My name is María (lit. I call myself María)
- **Me despierto a las siete** — I wake up at seven
- **Los niños se divirtieron mucho** — The children had a lot of fun

## Verbs That Change Meaning Reflexively

Some verbs have a related but distinct meaning when used with a reflexive pronoun:

| Non-reflexive | Meaning | Reflexive | Meaning |
|---------------|---------|-----------|---------|
| **ir** | to go | **irse** | to leave / go away |
| **dormir** | to sleep | **dormirse** | to fall asleep |
| **poner** | to put | **ponerse** | to put on (clothing) / to become |
| **llevar** | to carry / take | **llevarse** | to take away / get along with |
| **hacer** | to do / make | **hacerse** | to become |

- **El bebé se durmió** (seh door-MYOH) — The baby fell asleep
- **Me pongo el abrigo** (meh POHN-goh) — I put on my coat
- **¡Vete ya!** (BEH-teh yah) — Leave already! (from *irse*)
