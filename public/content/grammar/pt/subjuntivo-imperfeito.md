# Imperfect Subjunctive (Subjuntivo Imperfeito)

The imperfect subjunctive — **imperfeito do subjuntivo** — is used for hypothetical situations, unreal conditions, and wishes about the present or past. It's the tense behind all those "if I were..." sentences. The great news? Unlike the present subjunctive, the imperfect subjunctive is completely regular — every verb follows the same pattern, derived from the third-person plural of the pretérito perfeito.

## Formation

To form the imperfect subjunctive:

1. Take the **eles/elas** form of the pretérito perfeito
2. Remove the **-ram** ending
3. Add the imperfect subjunctive endings: **-sse, -sse, -ssemos, -ssem**

### -AR Verbs: falar → falaram → fala- → falasse

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | falasse |
| se você / ele / ela | falasse |
| se nós | falássemos |
| se vocês / eles / elas | falassem |

### -ER Verbs: comer → comeram → come- → comesse

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | comesse |
| se você / ele / ela | comesse |
| se nós | comêssemos |
| se vocês / eles / elas | comessem |

### -IR Verbs: partir → partiram → parti- → partisse

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | partisse |
| se você / ele / ela | partisse |
| se nós | partíssemos |
| se vocês / eles / elas | partissem |

- **Se eu falasse português fluente, eu moraria no Brasil** (see eh-oo fah-lah-see por-too-gesh floo-en-chee eh-oo moh-rah-ree-ah noo brah-zeel) — If I spoke fluent Portuguese, I would live in Brazil
- **Se ela comesse menos doce, se sentiria melhor** (see eh-lah koh-meh-see meh-nooz doh-see see sen-chee-ree-ah meh-lyor) — If she ate less candy, she would feel better
- **Se nós partíssemos agora, chegaríamos a tempo** (see nohs par-chee-seh-mooz ah-goh-rah sheh-gah-ree-ah-mooz ah tem-poo) — If we left now, we would arrive on time

## Irregular Verbs — Still Regular!

The beauty of the imperfect subjunctive is that even "irregular" verbs follow the same rule. Since they're based on the pretérito perfeito stem, the irregularity comes from the preterite, not the subjunctive endings.

### Ser/Ir (foram → fo- → fosse)

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | fosse |
| se você / ele / ela | fosse |
| se nós | fôssemos |
| se vocês / eles / elas | fossem |

- **Se eu fosse rico, viajaria pelo mundo** (see eh-oo foh-see hee-koo vee-ah-zhah-ree-ah peh-loo moon-doo) — If I were rich, I would travel the world
- **Se ele fosse mais paciente, teria mais amigos** (see eh-lee foh-see mahyz pah-see-en-chee teh-ree-ah mahyz ah-mee-gooz) — If he were more patient, he would have more friends

### Ter (tiveram → tive- → tivesse)

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | tivesse |
| se você / ele / ela | tivesse |
| se nós | tivéssemos |
| se vocês / eles / elas | tivessem |

- **Se eu tivesse mais tempo, estudaria mais** (see eh-oo chee-veh-see mahyz tem-poo esh-too-dah-ree-ah mahyz) — If I had more time, I would study more
- **Se nós tivéssemos dinheiro, compraríamos um carro** (see nohs chee-veh-seh-mooz jeen-yay-roo kon-prah-ree-ah-mooz ung kah-hoo) — If we had money, we would buy a car

### Fazer (fizeram → fize- → fizesse)

| Pronoun | Subjunctive |
|---------|-------------|
| se eu | fizesse |
| se você / ele / ela | fizesse |
| se nós | fizéssemos |
| se vocês / eles / elas | fizessem |

- **Se eu fizesse exercício, seria mais saudável** (see eh-oo fee-zeh-see eh-zer-see-see-oo seh-ree-ah mahyz sow-dah-vew) — If I exercised, I would be healthier

### More Common Irregular Stems

| Verb | Preterite (eles) | Stem | Subjunctive (eu) |
|------|-------------------|------|-------------------|
| estar | estiveram | estive- | estivesse |
| poder | puderam | pude- | pudesse |
| saber | souberam | soube- | soubesse |
| dizer | disseram | disse- | dissesse |
| trazer | trouxeram | trouxe- | trouxesse |
| ver | viram | vi- | visse |
| vir | vieram | vie- | viesse |
| dar | deram | de- | desse |
| querer | quiseram | quise- | quisesse |
| pôr | puseram | puse- | pusesse |

- **Se eu pudesse, iria com você** (see eh-oo poo-deh-see ee-ree-ah kong voh-seh) — If I could, I would go with you
- **Se eu soubesse a resposta, te diria** (see eh-oo soh-beh-see ah hesh-pos-tah chee jee-ree-ah) — If I knew the answer, I would tell you
- **Se ele viesse, seria ótimo** (see eh-lee vee-eh-see seh-ree-ah oh-chee-moo) — If he came, it would be great
- **Se eu quisesse, eu sairia** (see eh-oo kee-zeh-see eh-oo sah-ee-ree-ah) — If I wanted to, I would leave

## Usage 1: Hypothetical / Unreal Conditions

The most common use — expressing what would happen if something (that isn't true) were the case:

**Structure: Se + imperfeito do subjuntivo + conditional (futuro do pretérito)**

- **Se eu fosse você, não faria isso** (see eh-oo foh-see voh-seh now fah-ree-ah ee-soo) — If I were you, I wouldn't do that
- **Se eu morasse na praia, seria muito feliz** (see eh-oo moh-rah-see nah prah-yah seh-ree-ah mween-too feh-leez) — If I lived at the beach, I would be very happy
- **Se chuvesse menos, sairíamos** (see shoh-veh-see meh-nooz sah-ee-ree-ah-mooz) — If it rained less, we would go out
- **Se eu ganhasse na loteria, compraria uma ilha** (see eh-oo gahn-yah-see nah loh-teh-ree-ah kon-prah-ree-ah oo-mah eel-yah) — If I won the lottery, I would buy an island
- **Se eu soubesse cozinhar, faria um jantar especial** (see eh-oo soh-beh-see koh-zeen-yar fah-ree-ah ung zhan-tar esh-peh-see-ow) — If I knew how to cook, I would make a special dinner

## Usage 2: Wishes About the Present

Expressing what you wish were true right now:

- **Eu queria que você estivesse aqui** (eh-oo keh-ree-ah kee voh-seh esh-chee-veh-see ah-kee) — I wish you were here
- **Eu gostaria que ele fosse mais gentil** (eh-oo gosh-tah-ree-ah kee eh-lee foh-see mahyz zhen-cheel) — I would like him to be kinder
- **Ela queria que nós soubéssemos a verdade** (eh-lah keh-ree-ah kee nohs soh-beh-seh-mooz ah vehr-dah-jee) — She wished we knew the truth
- **Eu adoraria que fizesse sol amanhã** (eh-oo ah-doh-rah-ree-ah kee fee-zeh-see sow ah-mahn-yang) — I would love it if it were sunny tomorrow

## Usage 3: Polite Forms

The imperfect subjunctive makes expressions more polite and tentative:

- **Se você pudesse me ajudar, eu agradeceria** (see voh-seh poo-deh-see mee ah-zhoo-dar eh-oo ah-grah-deh-seh-ree-ah) — If you could help me, I would appreciate it
- **Se fosse possível, eu gostaria de trocar** (see foh-see poh-see-vew eh-oo gosh-tah-ree-ah jee troh-kar) — If it were possible, I would like to exchange
- **Se não fosse muito incômodo...** (see now foh-see mween-too een-koh-moh-doo) — If it weren't too much trouble...

## Usage 4: After "Como se" (As if)

- **Ele fala como se fosse brasileiro** (eh-lee fah-lah koh-moo see foh-see brah-zee-lay-roo) — He speaks as if he were Brazilian
- **Ela age como se soubesse tudo** (eh-lah ah-zhee koh-moo see soh-beh-see too-doo) — She acts as if she knew everything
- **Ele me trata como se eu fosse criança** (eh-lee mee trah-tah koh-moo see eh-oo foh-see kree-an-sah) — He treats me as if I were a child

## Putting It All Together

Here's a paragraph using the imperfect subjunctive naturally:

> **Se eu pudesse** voltar no tempo, **faria** muitas coisas diferentes. **Se eu soubesse** o que sei hoje, **teria** estudado mais. **Se eu morasse** em outro país, **aprenderia** outra língua. Mas a vida é assim — **se fosse** perfeita, não **seria** interessante!

Translation: If I could go back in time, I would do many things differently. If I had known what I know today, I would have studied more. If I lived in another country, I would learn another language. But life is like that — if it were perfect, it wouldn't be interesting!
