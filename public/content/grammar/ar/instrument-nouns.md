# Nouns of Instrument (ism al-ālah)

A noun of instrument, **اِسْمُ الْآلَةِ** (ismu al-ālati), names the tool or device used to perform an action. Many are built from familiar roots on recognizable patterns.

## Core idea

Instrument nouns connect vocabulary to roots. From **فَتَحَ** (fataḥa) — he opened, Arabic forms **مِفْتَاحٌ** (miftāḥun) — key, the tool used for opening. Not every modern tool is perfectly predictable, but the patterns are very useful.

## Forms and examples

| Pattern | Root verb | Instrument noun | Example |
|---|---|---|---|
| **مِفْعَالٌ** | **فَتَحَ** (fataḥa) — opened | **مِفْتَاحٌ** (miftāḥun) — key | **فَتَحَ الْوَلَدُ الْبَابَ بِالْمِفْتَاحِ** (fataḥa al-waladu al-bāba bi-l-miftāḥi) — the boy opened the door with the key |
| **مِفْعَلَةٌ** | **كَنَسَ** (kanasa) — swept | **مِكْنَسَةٌ** (miknasatun) — broom | **نَظَّفْتُ الْغُرْفَةَ بِالْمِكْنَسَةِ** (naẓẓaftu al-ghurfata bi-l-miknasati) — I cleaned the room with the broom |
| **مِفْعَلَةٌ** | **طَرَقَ** (ṭaraqa) — struck | **مِطْرَقَةٌ** (miṭraqatun) — hammer | **ضَرَبَ النَّجَّارُ الْمِسْمَارَ بِالْمِطْرَقَةِ** (ḍaraba an-najjāru al-mismāra bi-l-miṭraqati) — the carpenter hit the nail with the hammer |
| **فَعَّالَةٌ** | **غَسَلَ** (ghasala) — washed | **غَسَّالَةٌ** (ghassālatun) — washing machine | **الْغَسَّالَةُ جَدِيدَةٌ** (al-ghassālatu jadīdatun) — the washing machine is new |

## Usage notes

Instrument nouns often appear after **بِـ** when you say what tool was used: **كَتَبْتُ بِالْقَلَمِ** (katabtu bi-l-qalami) — I wrote with the pen. Some common tools, such as **قَلَمٌ** (qalamun) — pen, are not transparent on the common instrument patterns, so dictionaries remain important.

## Practice patterns

When you learn a new tool word, ask three questions:

- What root does it seem to contain?
- Which pattern does it resemble?
- Can it appear after **بِـ** in a sentence like **اِسْتَعْمَلْتُهُ بِـ...** (istaʿmaltuhu bi-...) — I used it with ...?
