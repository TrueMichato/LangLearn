# The Arabic Script: How Letters Join

Arabic is written from right to left, and most letters change shape depending on where they stand in a word. That sounds like a lot at first, but the idea is friendly: letters are still letters, just wearing different connected forms.

## Core idea

Arabic has 28 main letters. Most connect to the next letter on the left, but six letters connect only to the letter before them: **ا** (ʾalif) — long ā / carrier, **د** (dāl) — d, **ذ** (dhāl) — dh, **ر** (rāʾ) — r, **ز** (zāy) — z, and **و** (wāw) — w / ū. When one of these appears, the word has a tiny visual break after it.

A word like **بَيْتٌ** (baytun) — house is read as the connected sequence **بَـ** (ba-) — b + **ـيْـ** (-y-) — y + **ـتٌ** (-tun) — t with nominative tanwīn.

## Forms and examples

| Idea | Example |
|---|---|
| Separate letters | **بَاءٌ** (bāʾun) — the letter bāʾ, **يَاءٌ** (yāʾun) — the letter yāʾ, **تَاءٌ** (tāʾun) — the letter tāʾ |
| Connected word | **بَيْتٌ** (baytun) — house |
| A non-connector inside | **دَارٌ** (dārun) — house / dwelling; **د** (dāl) — d does not connect to the following **ا** (ʾalif) — ā |
| Another visual break | **وَرْدَةٌ** (wardatun) — rose; **و** (wāw) — w connects backward only |

## Usage notes

Do not worry about handwriting beauty yet. First, learn to recognize the skeleton of each word. Printed Arabic usually omits many short vowel marks, but LangLearn lessons show full tashkīl so your eye can connect spelling, sound, and meaning.

## Practice patterns

Try tracing the right-to-left flow:

- **كِتَابٌ** (kitābun) — book: **كِـ** (ki-) — k + **ـتَـ** (-tā-) — t + **ـابٌ** (-bun) — b ending.
- **مَدْرَسَةٌ** (madrasatun) — school: each letter connects smoothly until the final **ةٌ** (tun) — tāʾ marbūṭa ending.
- **زَمَانٌ** (zamānun) — time: **ز** (zāy) — z creates a break because it does not connect forward.
