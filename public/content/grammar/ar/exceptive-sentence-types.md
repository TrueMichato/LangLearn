# Exception Sentence Types with illā

Arabic exceptions with **إِلَّا** (illā) depend on the shape of the whole sentence. The three useful labels are complete affirmative, complete negative, and incomplete negative.

## Core idea

A complete sentence names the group before **إِلَّا** (illā). An incomplete negative sentence does not name that group, so the noun after **إِلَّا** (illā) simply fills the normal grammatical role needed by the sentence.

## Forms and examples

| Type | Arabic label | Pattern | Case after إِلَّا | Example |
|---|---|---|---|---|
| complete affirmative | **تَامٌّ مُوجَبٌ** (tāmmun mūjabun) | group is named; no negation | usually accusative | **حَضَرَ الطُّلَّابُ إِلَّا طَالِبًا** (ḥaḍara aṭ-ṭullābu illā ṭāliban) — the students attended except one student |
| complete negative | **تَامٌّ مَنْفِيٌّ** (tāmmun manfiyyun) | group is named; negation present | accusative or substitute case | **مَا حَضَرَ الطُّلَّابُ إِلَّا طَالِبٌ** (mā ḥaḍara aṭ-ṭullābu illā ṭālibun) — no students attended except one student |
| incomplete negative | **نَاقِصٌ مَنْفِيٌّ** (nāqiṣun manfiyyun) | no group before إِلَّا | normal role in sentence | **مَا حَضَرَ إِلَّا طَالِبٌ** (mā ḥaḍara illā ṭālibun) — only one student attended |
| incomplete with object | **نَاقِصٌ مَنْفِيٌّ** (nāqiṣun manfiyyun) | noun is an object | accusative as object | **لَمْ أَرَ إِلَّا طَالِبًا** (lam ara illā ṭāliban) — I saw only one student |

## Usage notes

In a complete affirmative exception, the excluded noun is the **مُسْتَثْنَى** (mustathnā) and is usually accusative. In a complete negative sentence, Arabic allows either accusative exception or a substitute matching the group’s case. In an incomplete negative sentence, do not force an accusative; read what the sentence still needs.

## Practice patterns

Notice how the case changes with the sentence type:

- **قَرَأْتُ الْكُتُبَ إِلَّا كِتَابًا** (qaraʾtu al-kutuba illā kitāban) — I read the books except one book.
- **مَا قَرَأْتُ الْكُتُبَ إِلَّا كِتَابًا** (mā qaraʾtu al-kutuba illā kitāban) — I read no books except one book.
- **مَا قَرَأْتُ إِلَّا كِتَابًا** (mā qaraʾtu illā kitāban) — I read only one book.
