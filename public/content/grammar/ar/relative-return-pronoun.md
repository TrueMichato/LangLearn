# The Return Pronoun in Relative Clauses

Arabic relative clauses often contain a small pronoun that points back to the noun being described. Traditional grammar calls it the ʿāʾid, the return pronoun.

## Core idea

English can say “the book that I read” without repeating “it.” Arabic usually keeps the link: **الْكِتَابُ الَّذِي قَرَأْتُهُ** (al-kitābu alladhī qaraʾtuhu) — the book that I read it, meaning the book that I read.

## Forms and examples

| Head noun role inside the relative clause | Arabic example | Return pronoun |
|---|---|---|
| Subject | **جَاءَ الطَّالِبُ الَّذِي نَجَحَ** (jāʾa aṭ-ṭālibu alladhī najaḥa) — the student who succeeded came | no separate pronoun |
| Direct object | **قَرَأْتُ الْكِتَابَ الَّذِي اشْتَرَيْتُهُ** (qaraʾtu al-kitāba alladhī ishtaraytuhu) — I read the book that I bought | **ـهُ** (-hu) |
| Object of a preposition | **زُرْتُ الْمَدِينَةَ الَّتِي وُلِدْتُ فِيهَا** (zurtu al-madīnata allatī wulidtu fīhā) — I visited the city in which I was born | **ـهَا** (-hā) |

## Usage notes

If the relative pronoun itself is the subject, a separate return pronoun is usually unnecessary. When the head noun is an object, possessor, or prepositional complement inside the clause, Arabic normally makes the link visible with an attached pronoun.

## Practice patterns

Notice how the suffix changes with the noun it points to:

- **هَذِهِ الْقِصَّةُ الَّتِي سَمِعْتُهَا** (hādhihi al-qiṣṣatu allatī samiʿtuhā) — this is the story that I heard.
- **هَذَا الْمُعَلِّمُ الَّذِي تَعَلَّمْتُ مِنْهُ** (hādhā al-muʿallimu alladhī taʿallamtu minhu) — this is the teacher from whom I learned.
- **تِلْكَ الْقَرْيَةُ الَّتِي عِشْتُ فِيهَا** (tilka al-qaryatu allatī ʿishtu fīhā) — that is the village in which I lived.
