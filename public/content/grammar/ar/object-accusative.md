# The Direct Object & Accusative (naṣb)

The direct object receives the action of the verb. In MSA, direct objects are normally accusative, a case called naṣb.

## Core idea

In **قَرَأَ الطَّالِبُ الْكِتَابَ** (qaraʾa aṭ-ṭālibu al-kitāba) — the student read the book, **الطَّالِبُ** (aṭ-ṭālibu) — the student is nominative subject, and **الْكِتَابَ** (al-kitāba) — the book is accusative object.

## Forms and examples

| Sentence | Object |
|---|---|
| **شَرِبَ الْوَلَدُ الْمَاءَ** (shariba al-waladu al-māʾa) — the boy drank the water | **الْمَاءَ** (al-māʾa) — the water, accusative |
| **فَتَحَتْ فَاطِمَةُ الْبَابَ** (fataḥat fāṭimatu al-bāba) — Fatima opened the door | **الْبَابَ** (al-bāba) — the door, accusative |
| **كَتَبْتُ رِسَالَةً** (katabtu risālatan) — I wrote a letter | **رِسَالَةً** (risālatan) — a letter, accusative |
| **أُحِبُّ اللُّغَةَ الْعَرَبِيَّةَ** (uḥibbu al-lughata al-ʿarabiyyata) — I love the Arabic language | object and adjective accusative |

## Usage notes

Word order can vary, but case endings help keep roles clear. **قَرَأَ الْكِتَابَ الطَّالِبُ** (qaraʾa al-kitāba aṭ-ṭālibu) — the student read the book still has the object accusative and subject nominative.

## Practice patterns

Indefinite accusative often uses **ـًا** (-an):

- **قَرَأْتُ كِتَابًا** (qaraʾtu kitāban) — I read a book.
- **أَكَلْتُ تُفَّاحَةً** (akaltu tuffāḥatan) — I ate an apple.
- **رَأَيْتُ وَلَدًا** (raʾaytu waladan) — I saw a boy.
