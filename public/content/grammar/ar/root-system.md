# The Root & Pattern System

Arabic vocabulary is famously built from roots and patterns. A root carries a field of meaning, and patterns shape that meaning into nouns, verbs, places, tools, and qualities.

## Core idea

The root **ك-ت-ب** (k-t-b) — writing appears in many related words. The consonants stay recognizable while vowels and extra letters create new patterns.

## Forms and examples

| Word | Meaning | Pattern idea |
|---|---|---|
| **كَتَبَ** (kataba) — he wrote | verb | basic action |
| **كِتَابٌ** (kitābun) — book | noun | thing connected to writing |
| **كَاتِبٌ** (kātibun) — writer | active participle |
| **مَكْتَبٌ** (maktabun) — office / desk | place / instrument pattern |
| **مَكْتَبَةٌ** (maktabatun) — library / bookstore | place with books |
| **مَكْتُوبٌ** (maktūbun) — written | passive participle |

## Usage notes

Patterns are not magic formulas for every word, but they are powerful clues. When you meet **مَدْرَسَةٌ** (madrasatun) — school, you can notice the root **د-ر-س** (d-r-s) — studying and the place-like pattern.

## Practice patterns

Another family:

- **عَلِمَ** (ʿalima) — he knew.
- **عِلْمٌ** (ʿilmun) — knowledge / science.
- **عَالِمٌ** (ʿālimun) — scholar.
- **مَعْلُومٌ** (maʿlūmun) — known.

Treat roots as memory hooks, not pressure.
