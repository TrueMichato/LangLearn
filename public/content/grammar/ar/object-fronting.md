# Fronting the Direct Object

Arabic word order is flexible, so a direct object can move before the verb for focus, contrast, or because the object is an interrogative or detached pronoun. The important point is that the fronted direct object remains accusative.

## Core idea

Basic order is often verb then subject then object: **قَرَأَ الطَّالِبُ الْكِتَابَ** (qaraʾa aṭ-ṭālibu al-kitāba) — The student read the book. For emphasis, MSA can front the object: **الْكِتَابَ قَرَأَ الطَّالِبُ** (al-kitāba qaraʾa aṭ-ṭālibu) — The book, the student read.

## Main cases of fronting

| Reason | Pattern | Example |
|---|---|---|
| Focus or contrast | Object first, still accusative | **الْقَصِيدَةَ حَفِظْتُ لَا الْمَقَالَةَ** (al-qaṣīdata ḥafiẓtu lā al-maqālata) — The poem I memorized, not the article. |
| Detached object pronoun | **إِيَّا** form before the verb | **إِيَّاكَ أَقْصِدُ** (iyyāka aqṣidu) — You specifically I mean. |
| Question object | Interrogative object first | **مَاذَا قَرَأْتَ؟** (mādhā qaraʾta?) — What did you read? |
| Topic with resumptive pronoun | Fronted noun plus pronoun inside clause | **الْكِتَابَ قَرَأْتُهُ** (al-kitāba qaraʾtuhu) — The book, I read it. |

## Emphasis and clarity

Fronting is especially useful for contrast: **هَذَا الدَّرْسَ فَهِمْتُ، أَمَّا ذَلِكَ فَلَا** (hādhā ad-darsa fahimtu, ammā dhālika fa-lā) — This lesson I understood, but that one I did not. The fronted object is not the subject; the verb ending still identifies the doer.

## Practice patterns

Detached object pronouns cannot attach before the verb, so Arabic uses **إِيَّا** (iyyā) forms: **إِيَّاهُ رَأَيْتُ** (iyyāhu raʾaytu) — Him specifically I saw. Ordinary nouns can be fronted without **إِيَّا**: **الْبَابَ فَتَحْتُ** (al-bāba fataḥtu) — The door, I opened.
