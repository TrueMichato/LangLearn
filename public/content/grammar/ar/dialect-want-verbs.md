# Wanting in the Dialects: ʿāyiz, badd, abghā, arīd, bghīt

MSA uses the regular verb أَرَادَ (arāda), so "I want" is أُرِيدُ (urīdu). Dialects often use very different everyday forms, and some behave more like adjectives or fixed expressions than like ordinary present-tense verbs.

## Core idea

Egyptian commonly uses عَايِز (ʿāyiz) for a male speaker and عَايْزَة (ʿāyza) for a female speaker. Levantine uses بَدِّي (baddī), Gulf often uses أَبْغَى (abghā), Iraqi uses أَرِيد (arīd), and Maghrebi uses بْغِيت (bghīt).

## Usage notes

Levantine بَدّ (badd) takes pronoun endings: بَدِّي (baddī), بَدَّك (baddak), بَدِّك (baddik), بَدُّه (baddu). Egyptian عَايِز (ʿāyiz) agrees with the speaker in gender, so a female speaker commonly says عَايْزَة (ʿāyza).

## Practice patterns

Use the dialect want-form before a noun or before another verb:

- Egyptian: عَايْزَة أَرُوح (ʿāyza arūḥ) — I want to go, said by a female speaker.
- Gulf: أَبْغَى أَتْعَلَّم (abghā atʿallam) — I want to learn.
- Maghrebi: بْغِيت نَمْشِي (bghīt nmshī) — I want to go.
