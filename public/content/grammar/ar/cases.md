# Case Endings (al-Iʿrāb): nominative, accusative, genitive

MSA uses case endings to show how a noun functions in a sentence. You will not hear every ending in casual speech, but recognizing them unlocks formal Arabic.

## Core idea

The three core cases are nominative **ـُ** (-u) / **ـٌ** (-un), accusative **ـَ** (-a) / **ـً** (-an), and genitive **ـِ** (-i) / **ـٍ** (-in). Definite nouns use single vowels; indefinite nouns often use tanwīn.

## Forms and examples

| Role | Definite | Indefinite |
|---|---|---|
| Nominative | **الْوَلَدُ** (al-waladu) — the boy | **وَلَدٌ** (waladun) — a boy |
| Accusative | **الْوَلَدَ** (al-walada) — the boy, object | **وَلَدًا** (waladan) — a boy, object |
| Genitive | **الْوَلَدِ** (al-waladi) — the boy, after prep/of | **وَلَدٍ** (waladin) — a boy, genitive |

## Usage notes

Case endings show relationships:

- **جَاءَ الْوَلَدُ** (jāʾa al-waladu) — the boy came: subject nominative.
- **رَأَيْتُ الْوَلَدَ** (raʾaytu al-walada) — I saw the boy: object accusative.
- **مَرَرْتُ بِالْوَلَدِ** (marartu bi-l-waladi) — I passed by the boy: after preposition, genitive.
