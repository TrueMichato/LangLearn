# Exception (al-Istithnāʾ with illā)

Arabic uses exception structures to say “except,” “other than,” and “only.” The most common word to recognize is إِلَّا.

## Core idea

The **الِاسْتِثْنَاءُ** (al-istithnāʾ) — exception marks something excluded from a larger statement. The particle **إِلَّا** (illā) — except / but introduces the exception.

## Forms and examples

| Pattern | Arabic | Translation |
|---|---|---|
| affirmative exception | **جَاءَ الطُّلَّابُ إِلَّا طَالِبًا** (jāʾa aṭ-ṭullābu illā ṭāliban) | the students came except one student |
| negative “only” | **مَا جَاءَ إِلَّا طَالِبٌ** (mā jāʾa illā ṭālibun) | only a student came |
| negative object focus | **لَا أُرِيدُ إِلَّا الْمَاءَ** (lā urīdu illā al-māʾa) | I want only the water |

## Usage notes

In a complete affirmative sentence, the exception after **إِلَّا** (illā) — except is often accusative: **طَالِبًا** (ṭāliban) — a student. In a negative “not...except” sentence, English often uses “only.”

## Practice patterns

Watch what the sentence is doing before translating:

- **قَرَأْتُ الْكُتُبَ إِلَّا كِتَابًا** (qaraʾtu al-kutuba illā kitāban) — I read the books except one book.
- **لَمْ أَقْرَأْ إِلَّا كِتَابًا** (lam aqraʾ illā kitāban) — I read only one book.

The same particle can feel like “except” or “only” depending on negation.
