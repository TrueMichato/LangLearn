# Conditional Sentences (idhā, law, in)

Conditionals help you connect cause and result: if this happens, that happens. Arabic has several “if” words with different flavors.

## Core idea

Use **إِذَا** (idhā) — if / when for real or likely conditions, **لَوْ** (law) — if for contrary-to-fact or hypothetical past situations, and **إِنْ** (in) — if for formal open conditions, often with jussive verbs.

## Forms and examples

| Conditional | Example |
|---|---|
| **إِذَا** (idhā) — if / when | **إِذَا دَرَسْتَ، نَجَحْتَ** (idhā darasta, najaḥta) — if you study, you succeed, masculine |
| **إِذَا** (idhā) — when | **إِذَا وَصَلْتُ، سَأَتَّصِلُ بِكَ** (idhā waṣaltu, sa-attaṣilu bika) — when I arrive, I will call you, masculine |
| **لَوْ** (law) — if | **لَوْ دَرَسْتَ، لَنَجَحْتَ** (law darasta, la-najaḥta) — if you had studied, you would have succeeded, masculine |
| **إِنْ** (in) — if | **إِنْ تَدْرُسْ، تَنْجَحْ** (in tadrus, tanjaḥ) — if you study, you succeed |

## Usage notes

In everyday MSA, **إِذَا** (idhā) — if / when is the safest and most common for real future situations. **لَوْ** (law) — if often imagines something unreal or missed.

## Practice patterns

Soft practice:

- **إِذَا كَانَ الْوَقْتُ مُنَاسِبًا، سَنَذْهَبُ** (idhā kāna al-waqtu munāsiban, sa-nadhhabu) — if the time is suitable, we will go.
- **لَوْ كَانَ الْجَوُّ جَمِيلًا، لَخَرَجْنَا** (law kāna al-jawwu jamīlan, la-kharajnā) — if the weather had been beautiful, we would have gone out.
